A **ENCETESTE** é um espaço dedicado à criação e divulgação de projetos relacionados a:

- 🌐 Desenvolvimento Web
- 📊 Ciência de Dados
- 🤖 Automação
- 🔎 Web Scraping
- 🎓 Workshops e Capacitação
- 📚 Compartilhamento de Conhecimento

Nosso objetivo é desenvolver soluções abertas, documentadas e reutilizáveis para apoiar aprendizado, inovação e colaboração.
